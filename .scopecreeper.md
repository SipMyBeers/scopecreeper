# .scopecreeper.md

## What this project IS
- A scope-drift detection tool for developers — scores how delusional a project plan is (0-100)
- A web app (scopecreeper.ai) with a retro-arcade UI: scan → skill tree → leaf artifacts
- Three leaf artifact types: SHIPPABLE (1-page PRD), KILL (abandon autopsy), ISSUE (GitHub issue body)
- A Claude Code MCP server (`@scopecreeper/mcp`) exposing `scan`, `kill`, `shippable` tools
- A GitHub App that audits PRs on-demand via `/scope-creeper` trigger comment
- A Cloudflare Pages + Workers AI stack (Llama 3.3 70B, edge runtime, KV for sessions)
- A monorepo: `apps/web` (Next.js), `apps/mcp` (MCP server), `packages/core` (shared scoring logic)

## What this project is NOT
- A general-purpose AI coding assistant or chat interface
- A CI/CD pipeline tool or code quality linter
- A project management platform (no boards, no sprints, no assignments)
- A team collaboration tool (single-user sessions, no multi-user workspaces)
- A SaaS with complex org/role management
- A code execution or sandbox environment

## In-flight scope (next 30 days)
- Shareable thread URLs (`/t/[slug]`) — public read-only view of a scan tree
- Pro tier ($9/mo) via Stripe: unlimited scans, all artifact types, share links
- Repo deep-audit: async tarball walk + grep heuristics + narrative report
- `ArcadeCollapsedHeader` — arcade animates to 64px strip after first scan
- GitHub App: auto status check on PR open + sync (informational, never blocking)

## Explicitly deferred
- Multi-user accounts or team workspaces
- Compare mode (two repos side-by-side)
- Public leaderboard of highest-scoring repos
- Chrome extension
- Mobile-native app
- Streaming token-by-token output
- `OPEN AS PR DRAFT` artifact action (requires GitHub OAuth + branch creation)
